# reference/

Third-party material kept for reference. Nothing here is built into BandLink firmware.

| Folder | What it is | License |
|---|---|---|
| `osptek-amoled-1.73-co5300/` | Osptek vendor package for the 1.73" 466×466 CO5300 AMOLED: datasheets, CO5300 init sequence, ESP32-S3 + LVGL examples | MIT (see its `LICENSE`) |

The ESP32-S3 examples are useful for the CO5300 init sequence, QSPI command format, and TE handling when writing `drivers/co5300/` for the STM32.
