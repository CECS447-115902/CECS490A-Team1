## 产品简介

OSPTEK **1.73 寸 466×466 AMOLED** 是一款 **QSPI** 接口圆形彩色显示模组，显示驱动为 **CO5300**，触摸驱动为 **CST820**。适合穿戴表盘、圆形仪表与小型圆形 HMI 等场景。

规格标识（仓库名）：`amoled-1.73-466x466-qspi-co5300`

当前模组版本：**AM173Q466466FLS32**。电气与外形细节以 [`docs/AM173Q466466FLS32.pdf`](./docs/AM173Q466466FLS32.pdf) 为准。
